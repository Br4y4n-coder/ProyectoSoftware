## Descripción del Proyecto

El proyecto consiste en el desarrollo de una aplicación web para la gestión de tickets de soporte técnico. Su objetivo es centralizar las solicitudes de los usuarios, permitiendo registrar incidencias, asignarlas a agentes de soporte, realizar seguimiento de su estado y gestionar su resolución de manera organizada. Con esta solución se busca mejorar el control de las solicitudes, optimizar los tiempos de atención y facilitar la comunicación entre usuarios, técnicos y administradores.
